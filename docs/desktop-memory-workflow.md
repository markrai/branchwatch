# Desktop Memory: Phase 6

1. Select a virtual desktop. Capture requires the desktop to be active.
2. Capture and review a saved layout. Assign optional application folders, then save or replace explicitly. Expand the captured monitor/window inventory for detail.
3. Preview restoration. Review monitor matching, choose the missing-monitor policy, and select individual windows. Normal placements not marked for review start selected; review-required placements start unchecked. Non-normal or unplaceable windows cannot be selected. Select all eligible is an explicit inclusion of review-required placements. The schematic shows selected proposed positions only. Changing fallback retains eligible selections but does not automatically select new placements. Refreshing the preview resets window selection to safe defaults.
4. Optionally enable launching missing applications. Click Restore selected and review the live matching/launch confirmation. Unselected windows are neither moved nor launched. All saved windows still participate in identity ambiguity checks. No snapshot is edited by selecting restore windows.
5. Review incremental per-window results and progress. Cancel stops future operations, not previously issued requests. An open-only folder request remains unverified. The final count distinguishes intentionally unselected windows from other incomplete outcomes.

All Phase 3–5 restrictions remain. No automatic restoration, window-state conversion, or cross-desktop movement was added. Native placement and launch remain subject to hardware qualification.

## Manual UI qualification

- Open the page on an active and inactive desktop, capture and save, inspect the diagram and expand/collapse the captured inventory.
- Preview a snapshot with normal, review-required, and minimized/maximized placements; verify initial selection, individual selection, select all, clear, safe defaults and disabled ineligible controls.
- Change fallback and refresh; verify new fallback placements are not silently selected. Switch desktops and verify restore disabled for inactive targets.
- Select only one of several running windows, approve, confirm others were not moved. Repeat with missing-app launch enabled and confirm unselected apps do not launch. Check live result rows, cancellation, close/navigation, final count and keyboard accessibility.
- Review layout at small settings-window size and mixed DPI. Phase 7 provides the [hardware qualification harness](desktop-memory-hardware.md). Physical qualification is not yet complete.
